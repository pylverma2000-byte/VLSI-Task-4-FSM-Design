# RTL Design of Finite State Machines (FSM) and Control Units

This repository contains my **Task 4** submission for the **MainCrafts VLSI Design Internship**. In this task, I explored the design and simulation of **Finite State Machines (FSMs)** using **Verilog HDL** and verified their behavior through testbenches and waveform analysis.

## Project Overview

Finite State Machines (FSMs) are an important part of digital and VLSI design, as they are widely used to implement sequential control logic. This project focuses on understanding FSM concepts and implementing real-world control circuits at the RTL level.

## Implemented Designs

* Moore Finite State Machine (FSM)
* Mealy Finite State Machine (FSM)
* Traffic Light Controller
* 1011 Sequence Detector
* Verilog Testbenches for each design
* Simulation and waveform verification

## Tools Used

* Verilog HDL
* Vivado Simulator
* EDA Playground
* GTKWave (for waveform analysis)
